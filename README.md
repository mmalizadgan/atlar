# آتلار (ATLAR) — فروشگاه پارچه مبلی

فروشگاه اینترنتی جنگو برای فروش پارچه مبلی، با ورود مشتری از طریق شماره موبایل + کد یکبار مصرف (OTP)، پنل مدیریت اختصاصی برای پارچه‌ها، و درگاه پرداخت بله‌پی.

## پشته فنی
- **Backend:** Django 5.2 LTS (پشتیبانی رسمی تا ۲۰۲۸) — نیازمند **Python 3.10 یا بالاتر**
- **دیتابیس:** PostgreSQL
- **فرانت:** Django Templates + Bootstrap 5 RTL (لوکال، بدون CDN) + فونت وزیرمتن (لوکال)
- **استاتیک:** WhiteNoise (فشرده‌سازی و سرو مستقیم از اپ)

> اگه موقع `pip install -r requirements.txt` خطای «نسخه پیدا نشد» گرفتی، اول `python3 --version` رو چک کن — این پروژه با Python 3.10 تا 3.13 تست شده.

## راه‌اندازی سریع (لوکال)

```bash
# ۱) محیط مجازی و پکیج‌ها
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

# ۲) دیتابیس PostgreSQL بساز (اگر از قبل نصب نیست، اول نصبش کن)
sudo -u postgres psql -c "CREATE USER atlar_user WITH PASSWORD 'atlar_dev_pass_2026';"
sudo -u postgres psql -c "CREATE DATABASE atlar_db OWNER atlar_user;"

# ۳) فایل .env از قبل با همین مقادیر آماده است — اگر رمز/نام دیتابیس رو عوض کردی، همین‌جا هم به‌روز کن

# ۴) مایگریشن و اجرا
python manage.py migrate
python manage.py runserver
```

سایت روی `http://127.0.0.1:8000` بالا میاد.

### داده نمونه (اختیاری)
برای اینکه فروشگاه از همون اول خالی نباشه:
```bash
python manage.py seed_demo_data
```
۴ دسته‌بندی و ۶ پارچه نمونه می‌سازه (قابل ویرایش/حذف از پنل مدیریت).

### ورود به پنل مدیریت
یک حساب مدیر پیش‌فرض ساخته شده:
- آدرس: `/admin/`
- شماره موبایل: `09120000000`
- رمز عبور: `Atlar@Admin2026`

**⚠️ حتماً این رمز رو همین اول عوض کن** (از پنل ادمین یا با `python manage.py changepassword 09120000000`).

## تنظیمات مهم قبل از رفتن روی سرور اصلی (production)

همه از طریق فایل `.env` تنظیم می‌شن (نمونه کامل در `.env.example`):

### ۱) پیامک OTP
الان روی `SMS_PROVIDER=console` تنظیم شده — یعنی به‌جای ارسال واقعی، کد رو توی ترمینال/لاگ چاپ می‌کنه (برای تست بدون هزینه). وقتی سرویس پیامکی واقعی گرفتی:
- در `accounts/services/sms.py` یک تابع `_send_via_<provider>` مثل نمونه‌ی کاوه‌نگار که آماده‌ست اضافه/تنظیم کن
- در `.env`: `SMS_PROVIDER=kavenegar` و `SMS_API_KEY=...` رو پر کن

### ۲) درگاه پرداخت بله‌پی
فایل `payments/gateways/bale_pay.py` با الگوی استاندارد درگاه‌های ایرانی (ایجاد تراکنش → ریدایرکت → verify) نوشته شده، اما **آدرس دقیق API و نام پارامترها رو باید از مستندات رسمی که بعد از فعال‌سازی به شما می‌دن جایگزین کنی** — این مستندات فقط بعد از فعال‌سازی از طریق ربات `@botfather` در بله (ارتقای کیف پول به سطح ۲ + ثبت اطلاعات بانکی) در اختیارت قرار می‌گیره و در وب عمومی منتشر نیست، پس نخواستم آدرس حدسی بذارم که خراب کار کنه.
مقادیر لازم: `BALE_PAY_MERCHANT_ID` و `BALE_PAY_API_KEY` در `.env`.

### ۳) امنیت production
```
DEBUG=False
SECRET_KEY=<یک کلید تصادفی جدید و طولانی>
ALLOWED_HOSTS=yourdomain.com
CSRF_TRUSTED_ORIGINS=https://yourdomain.com
```
با `DEBUG=False`، تنظیمات امنیتی (HSTS، کوکی امن، ریدایرکت HTTPS) خودکار فعال می‌شن.

### ۴) استاتیک و مدیا
```bash
python manage.py collectstatic
```
فایل‌های media (تصاویر پارچه‌ها) روی فضای دیسک سرور ذخیره می‌شن؛ برای مقیاس بزرگ‌تر می‌تونی بعداً به S3/آبان‌ابر و مشابه اونا مهاجرت کنی.

## ساختار پروژه
- `accounts/` — کاربر سفارشی (شماره موبایل)، ورود OTP، پروفایل
- `products/` — **کالیته** (نوع/طرح پارچه: قیمت، جنس، طرح، مقاومت سایش) و **رنگ‌بندی** (هر رنگ با تصویر و موجودی جدا؛ چند رنگ‌بندی برای هر کالیته)
- `cart/` — سبد خرید (سشن‌بیس؛ هر ردیف به یک رنگ‌بندی مشخص وصله، نه فقط به کالیته)
- `orders/` — سفارش‌ها، چک‌اوت، آدرس ارسال (اسم کالیته + رنگ در لحظه‌ی خرید اسنپ‌شات می‌شه)
- `payments/` — اتصال به بله‌پی (`payments/gateways/`)
- `core/` — صفحه اصلی، درباره ما، تنظیمات عمومی سایت از جمله **عرض ثابت رول پارچه** (از پنل ادمین قابل ویرایش)

### افزودن پارچه از پنل ادمین
هر «کالیته» (مثلاً «مخمل سلطنتی») یک بار ساخته می‌شه؛ رنگ‌بندی‌هاش (زرشکی، طوسی، ...) مستقیم توی همون صفحه، پایین فرم، به‌صورت ردیف‌های قابل‌افزودن هستن — هرکدوم تصویر و موجودی جدا داره. اگه برای یک رنگ خواستی چند عکس گالری اضافه کنی، از «Products → Fabric color variants» همون رنگ رو باز کن.
عرض رول (که برای همه‌ی پارچه‌ها ثابته) از «Core → Site settings» تنظیم می‌شه، نه توی فرم هر پارچه.

## عملکرد و بهینه‌سازی که در پروژه رعایت شده
- کوئری‌های دیتابیس با `select_related`/`prefetch_related`
- صفحه‌بندی (pagination) روی لیست پارچه‌ها
- فونت و بوت‌استرپ لوکال (بدون درخواست به سرور خارجی) + فشرده‌سازی WhiteNoise
- تصاویر با `loading="lazy"` (به‌جز تصویر اصلی صفحه محصول)
- کش با `django.core.cache` (پیش‌فرض in-memory؛ برای production می‌تونی به Redis سوییچ کنی — فقط `CACHES` در `settings.py` رو عوض کن)

## تنظیمات سایت از پنل ادمین
بخش «Core → Site settings» توی پنل مدیریت: نام سایت، شعار، متن درباره ما، شماره تماس، آدرس، آیدی اینستاگرام — بدون نیاز به تغییر کد.
